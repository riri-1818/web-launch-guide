制作側がやること

オーストラリアのスパム法（Spam Act 2003）営業メールは、原則として相手の同意が必要で、送り主の名前と連絡先、配信停止の方法を入れることが義務です（停止は5営業日以内）。お店が公開しているアドレスでも、公開されているだけでは同意にはなりません。例外（Schedule 2 の 4(2)）として認められるのは、特定の人や役職（オーナー、店長など）あてのアドレスが、本人の了解のうえで目立つ形で公開され、「営業メールお断り」の記載がなく、内容がその人の仕事に関係する場合です。info@ のような共用アドレスが当てはまるかははっきりしません。迷ったら専門家に聞いてください。

  2. ドメイン名を www なしで入れる → 今のレコードを自動で読み込む（DNS records quick scan）を選ぶ → Continue → プランは Free
  3. 取り込まれたDNSレコードを、1回目の前に記録したものと1行ずつ突き合わせる。足りないものは Add record で足す
確かめるもの何のため注意
MX（全部）メールを受け取る優先度（Priority）の数字も同じに
TXT：v=spf1 で始まるもの迷惑メール扱いされないため1つのドメインに1行だけ
TXT：_dmarc同上なければ無理に足さなくてよい
〇〇._domainkey（DKIM）同上Google は google._domainkey、Microsoft は selector1/selector2

A・CNAME（@ と www）今のサイト公開の瞬間まで残す
CAA（あれば）https の証明書をどこが発行してよいかの指定前の会社だけに絞られていると、Cloudflare の証明書が出ない。あれば Cloudflare が使う発行元も許可する

2回目の面談＝公開日

最初にネームサーバーを書き換え、Cloudflare に切り替わるのを待つあいだに、最終確認と説明を済ませます。早ければ数分〜数時間で切り替わり、面談中に公開まで終わります。Cloudflare の案内では最大24時間、管理会社によっては48時間とされているので、面談中に終わらなくても慌てなくて大丈夫です（STEP 04）。

困ったとき・よくある質問

ドメイン管理会社にログインできない

ログイン画面の「パスワードを忘れた」から再設定。メールも分からなければ、管理会社のサポートに本人確認を依頼します（登録したときの ABN・会社名・メールアドレスなどを用意しておくと話が早いです）。2回目までに解決しなければ、公開は3回目にします。

ドメインが前の制作会社の名義になっている

名義をお客様に移してもらうよう依頼します。数日〜数週間かかるので、1回目の面談の直後に始めます。

ネームサーバーを変えたのに24時間たっても Active にならない

入力ミス（綴り違い・Cloudflare 以外のネームサーバーが残っている）、DNSSEC の情報が管理会社に残っていないか、保存し忘れや別のドメインを書き換えていないかを確かめます。管理会社によっては、確認メールの承認が要ることもあります。

メールが届かなくなった

MX が記録どおりか、メール用の行がオレンジの雲になっていないかを確かめます。

送ったメールが相手の迷惑メールに入る

SPF と DKIM の行が残っているか、SPF が2行になっていないかを確かめます。

新しいサイトが自分のスマホだけ出ない

古い情報が残っているだけのことが多いです。携帯回線に切り替えるか、数時間待ちます。

「この接続は安全ではありません」と出る

Custom domains で、そのドメインが Verifying（確認中）のままになっていないか見ます。進まないときは、CAA レコードが Cloudflare の発行元を許可しているか、転送ルールや Worker が確認を邪魔していないかを確かめます。15分たっても Verifying のままなら、Cloudflare 公式はサポートへの問い合わせを勧めています。

Cloudflare の画面がこの手順書と違う

Cloudflare は画面の名前がよく変わります。この手順書は2026年10月時点です。上の検索バーで英語の名前（Custom domains など）を入れると早く見つかります。

Wix や Squarespace でサイトのプランを解約すると、ドメインも消える？

消えません。どちらもサイトのプランとドメインは別の契約で、プランを解約してもドメインは解約されません（Wix・Squarespace 公式）。ドメインの自動更新はオンのままにしておきます。

毎月の費用はいくらかかる？

Cloudflare の無料プランと Pages の無料枠で、お店のサイトなら月額0円で動きます（Cloudflare 公式：静的なページへのアクセスは無料・無制限、無料プランのビルドは月500回まで）。かかるのは、今までどおりのドメイン代（管理会社へ。.au は1〜5年ごとの更新）と、メールのサービス代（Google Workspace などを使っている場合）だけです。

ドメインごとCloudflareに移した方がいい？

必要ありません。そもそも Cloudflare のドメイン管理（Cloudflare Registrar）は .com.au を扱っていません（2026年10月時点の公式一覧）。管理会社はそのままで、案内表だけ移します。

新しいドメインを取る場合は？

1回目の面談のあとにお客様名義で購入してもらいます。DNSの突き合わせが不要になるので、2回目で公開しやすくなります。

  • Microsoft：SMTP DANE：新しい MX の形式（…mx.microsoft）と従来の …mail.protection.outlook.com
  • ACMA：Spam Act の違反通知（例）：公開アドレスだけでは同意にならない（Schedule 2 4(1)）、例外は 4(2)、メール内に配信停止の宛先を書く義務（18条）

  • Wix：サイトプランの解約：プランを解約してもドメイン・メール・アプリは解約されない
